# AIDA AI MVP

MVP-сервис для генерации Instagram-идей, каруселей и сторис.

## Быстрый старт

```bash
npm install
npm run dev
```

Открой: `http://localhost:3000`

## Что умеет

- Онбординг: ниша, аудитория, цель
- Генерация 5 идей
- Выбор идеи и генерация карусели (6 слайдов)
- Адаптация в сторис (5 экранов)

## Стек

- Next.js (App Router)
- React
- TailwindCSS
- TypeScript
