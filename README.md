# AIDA AI MVP

MVP-сервис для генерации Instagram-идей, каруселей и сторис с дизайн-средой.

## Быстрый старт

```bash
npm install
npm run dev
```

Открой: `http://localhost:3000`

## Что умеет

- Онбординг: ниша, аудитория, цель
- Генерация 5 идей
- Выбор идеи и генерация карусели (6 слайдов)
- Дизайн-режим с автолейаутом слайдов под длину текста
- Переключение дизайн-шаблонов (Bold Red / Clean Dark / Mono Grid)
- Интерпретация текста: меньше / баланс / больше
- Адаптация в сторис (5 экранов)

## Стек

- Next.js (App Router)
- React
- TailwindCSS
- TypeScript
